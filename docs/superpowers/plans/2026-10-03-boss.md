# Boss — plan d'implémentation

> Exécution inline (superpowers:executing-plans). Conception : `docs/superpowers/specs/2026-10-03-boss-design.md`.

**Goal:** 6 boss pilotés par un cerveau pur (3 phases, catalogue d'attaques), testés en Lua 5.1.

- [ ] **Task 1 — Tests du cerveau (rouge).** `tests/test_boss_brain.lua` avec un contexte factice
  (enregistre tirs, bombes, invocations, effets ; `shotCount` réglable) : fiches valides ; phases à
  66/33 %, `bossInvuln` 1 s, `clearShots` appelé, événement `phase` ; `radial` = N tirs, `fan` = N tirs
  visés, `ring_gap` = N − trou, `spiral` étalée sur sa durée ; plafond de 60 ; dégâts × chapitre ×
  admin ; 90 s simulées par boss sans erreur et tous les types de leurs fiches exécutés.
  Ajouter la suite à `tests/run.lua`.
- [ ] **Task 2 — `src/data/bosses.lua`.** Catalogue `ATTACKS` + fiches `DEFS` des 6 boss (tableau de
  la conception), constantes (`PHASE_AT`, `STAGGER_TIME`, `MAX_SHOTS`, `DAMAGE_PER_CHAPTER`).
- [ ] **Task 3 — `src/core/boss_brain.lua`.** `has(type)`, `update(dummy, dt, ctx)`,
  `telegraph(dummy)`, exécuteurs par type, déplacements. Tests verts. Commit.
- [ ] **Task 4 — Branchement IA.** `AIController.update` → cerveau pour les boss à fiche, contexte
  unique réutilisé (pools, physique, VFX/Audio/Banner via `fx`), `canTakeDamage` respecte
  `bossInvuln`, ancienne rage désactivée pour eux ; `drawTelegraph` pour les boss ;
  `spawnMonstersNow` renseigne `d.chapterIndex`. Repères 66/33 % sur la barre de boss.
  Autotest : chaque boss tué à travers ses 3 phases. Commit.
- [ ] **Task 5 — Mesures.** Banc PC + Azahar (salles 10…60) : FPS, aucune erreur ; capture d'un boss
  par chapitre ; ajustements. README. Commit, fusion.
